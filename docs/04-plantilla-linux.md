# Fase 5. Plantilla Linux

## Objetivo
Crear una plantilla Linux ligera y reutilizable para desplegar máquinas virtuales destinadas al servidor y al cliente.

La plantilla permite evitar instalaciones repetitivas y mantener una configuración inicial común.

## Procedimiento

## 1. Características de la plantilla

>- **Nombre:** linux-template
>- **Sistema operativo:** Debian 12 minimal
>- **Tipo:** Máquina virtual
>- **Virtualizador:** Proxmox VE
>- **Hostname base:** linux-template
>- **Usuario administrativo:** administrador
>- **Acceso remoto:** SSH
